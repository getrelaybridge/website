# Security policy

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public GitHub issue.

Until a dedicated security mailbox is confirmed, email `info@getrelaybridge.com` with:

- the affected website page or RelayBridge component;
- a concise description of the issue and its impact;
- reproduction steps where safe; and
- any relevant version, browser, or environment information.

Do not include active secrets, private keys, customer mail, tenant identifiers, or other sensitive production data. Use a minimal sanitized example.

## Scope

This repository contains the RelayBridge public website. Reports about website source, content-security behavior, static hosting configuration, or dependency issues belong here.

Product security reports may use the same private email contact until dedicated public product-security guidance is published.
